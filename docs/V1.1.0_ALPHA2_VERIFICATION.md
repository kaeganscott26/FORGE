# FORGE v1.1.0-alpha.2 Verification Record

## Immutable release boundary

- `v1.1.0-alpha.1` and its five published assets are historical and must not be edited.
- v1.0.1 remains the GitHub Latest stable release.
- Alpha.2 may be published only from an annotated tag on synchronized `main`, as a GitHub Pre-release.
- Every published artifact must originate from the tag target and report that exact commit in About diagnostics.

## Update policy under test

FORGE sets the Stable feed to `latest` with prereleases excluded and the Preview feed to `preview` with prereleases enabled. After setting either channel it resets `allowDowngrade=false`. Electron Updater automatic download is disabled; FORGE downloads only after its own SemVer gate proves the candidate is valid, strictly newer, and eligible for the selected channel.

Automated cases cover:

| Installed | Candidate | Channel | Expected |
| --- | --- | --- | --- |
| 1.0.1 | 1.1.0-alpha.1 / alpha.2 / beta.1 | Stable | reject prerelease |
| 1.0.1 | 1.1.0 | Stable | accept forward stable |
| 1.0.1 | 1.1.0-alpha.1 | Preview | accept |
| 1.1.0-alpha.1 | 1.1.0-alpha.2 | Preview | accept |
| 1.1.0-alpha.2 | 1.1.0-alpha.1 or 1.0.1 | Preview | reject downgrade |
| 1.1.0-alpha.2 | 1.1.0-beta.1 | Preview | accept |
| 1.1.0-beta.1 | 1.1.0 | Preview | accept |
| 1.1.0 | 1.1.0-beta.1 | Preview | reject downgrade |
| any valid version | equal, older, or malformed | either | reject |
