# FORGE Documentation Archive

This directory preserves historical evidence that no longer describes current runtime behavior. Archived files may contain old versions, paths, package names, approval models, release procedures, future plans, or incomplete findings. Do not use them as implementation or release instructions without reconciling them against current source and active documentation.

## Contents

- `audits/` — dated branch/runtime audits and superseded review reports.
- `implementation/` — completed implementation/repair logs.
- `planning/` — superseded development arcs, market/architecture proposals, and future-state designs.
- `releases/` — immutable verification records for older published releases.
- `PC_SECURITY_AUDIT_PROMPT.md` and `PRE_BETA_RELEASE_AUDIT.md` — historical security/release prompts retained for chronology.

Current entry points are [the project README](../../README.md), [the documentation index](../README.md), [Project Status](../PROJECT_STATUS.md), [Architecture](../ARCHITECTURE.md), and [Releasing FORGE](../../RELEASING.md).
