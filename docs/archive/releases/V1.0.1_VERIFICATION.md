## Update boundary

The update provider is declared in package metadata and explicitly configured in `UpdaterService`. The renderer polls through `checking`, `available`, and `downloading`, then exposes **Restart to update** at `downloaded`. The generated `latest-mac.yml` must report `1.0.1` and match the published ZIP digest.

No Apple Developer ID or notarization secrets are configured. Detection and feed validation are testable, but unattended macOS replacement is not classified as trusted until releases share a valid signing identity. The supported fallback is the release DMG.
