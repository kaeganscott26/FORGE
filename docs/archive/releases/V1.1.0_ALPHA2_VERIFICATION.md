## Update policy under test

Alpha.2 sets the Stable feed to `latest` with prereleases excluded and maps logical Preview to a provider feed called `preview`. After setting either channel it resets `allowDowngrade=false`. Electron Updater automatic download is disabled; FORGE downloads only after its own SemVer gate proves the candidate is valid, strictly newer, and eligible for the selected channel. The SemVer gate is sound, but the Preview provider mapping is incompatible with conventional GitHub `alpha`, `beta`, and `rc` tags. Alpha.3 replaces that mapping with bounded release discovery.

## Final-suite watcher finding

The first suite after the documentation commit passed 54 of 55 tests and timed out waiting for one macOS filesystem event. Investigation showed that `fs.watch` can report the watched directory name rather than the changed child; the implementation intentionally filtered that directory-level event and therefore had no signal to publish. `NodeFileSystem` now reconciles its before/after snapshot when it receives a missing or directory-level filename and updates the snapshot after normal native events. The focused lifecycle/watcher file then passed ten consecutive runs. Because this is a source change, the resulting commit requires the complete exact-commit suite and packaging gates again.
