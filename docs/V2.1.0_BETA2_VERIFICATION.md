## Scope

This release contains the post-reset repairs for the interactive workspace explorer, text-file editing, model discovery, action reporting, and responsive layout behavior. It supersedes and removes the incorrectly published beta.1 artifact line.

## Feature evidence

- Workspace tests exercise recursive tree listing, arbitrary UTF-8 extension reads, writes, and copy without overwrite.
- Renderer tests exercise normalized paths, parent/child explorer paths, and collision-safe copy names.
- Explorer supports folder expansion/collapse, context actions, new file/folder, rename, delete, copy, paste, and keyboard shortcuts.
- The editor opens unknown UTF-8 text extensions as plain text and maps major coding languages to Monaco grammars.
- Saved remote credentials and loopback providers automatically request model catalogs; manual refresh and exact model validation remain available.
- Layout values are clamped when loaded, resized, and persisted; narrow windows hide secondary panels to protect editor readability.

## Artifact acceptance policy

- The beta.2 package is built from the exact tagged patched commit, never from a source directory installed over an existing app.
- The DMG is mounted read-only and inspected in a temporary location. The acceptance run does not overwrite `/Applications/FORGE.app` or `~/Applications/FORGE.app`.
- The packaged app is launched from the mounted/test copy with a temporary user-data directory and its renderer must load from `file://.../app.asar`.
- The embedded version, source commit, architecture, and UI strings are checked against the build manifest before publication.

## Release gates

- Annotated tag target and workflow head match the final source commit.
- Universal DMG, ZIP, both blockmaps, and `beta-mac.yml` match local SHA-256 hashes after public download.
- Packaged runtime and isolated DMG smoke test pass.
