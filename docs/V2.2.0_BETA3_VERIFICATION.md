## 🧭 Scope

This beta adds a protected, native-rendered FORGE Browser with Home, tabs, workspace-scoped bookmarks/history, and explicit agent page-context tools. It also bounds durable-memory retrieval before scoring and provider handoff to prevent oversized workspace records from exhausting the runtime. The release manifest treats only the verified generated desktop runtime bundle as packaging output, while still rejecting every other source change before upload.
